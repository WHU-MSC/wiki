2. 观察下面的定义，尝试进行推演运算，并推测 `Y` 的性质：

```
g(x) = x(x)
W(f)(x) = f(g(x))
Y(f) = W(f)(W(f))
```

针对任意形如 `f(...) = ... f(...) ...` 的递归函数，你可以通过使用 `Y` 将其重新构造成一个 **不直接进行递归** 的函数吗？

### 提示材料

* 柯里化：任何函数都是一元函数。`add(x, y)` 可以被写做 `add(x)(y) = x + y`。你可以进行“部分应用”，如：`add(1)(y) = 1 + y`；注意你此时其实创造了一个新的函数，直观上这个函数或许可以被叫作……`add(1)`？

* 递归总可以写成 `f = g(f)`。你当然可以不把它当成定义，而当成是一个等式、一条性质。`f` 和 `g` 的关系是？想想 `Y` 呢？
